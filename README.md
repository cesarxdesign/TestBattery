# TestBattery

My calls on the roles [JobRadar](https://github.com/cesarxdesign/JobRadar) finds, held against what its filter says.

JobRadar reads job postings and sorts them into lanes. Each role I would take, each reason I flagged as wrong and each role I moved to another lane is a known answer. The battery checks the filter against those answers, and this page lists each role where the two disagree, with the words that decided it. The goal is an empty page.

`battery.json` is written by `battery.py` in JobRadar.

Live: https://cesarxdesign.github.io/TestBattery/
